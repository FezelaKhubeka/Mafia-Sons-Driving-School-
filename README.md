# Mafia & Sons Driving School

A modern, professional website for a driving school brand. This project showcases the school’s services, values, and contact information in a clean, easy-to-navigate layout.

## Live Demo

The website is published using GitHub Pages here:

https://fezelakhubeka.github.io/Mafia-Sons-Driving-School-/

## Overview

Mafia & Sons Driving School is a driving school business website designed to:

- Promote driving lessons and training packages
- Highlight professionalism and student confidence
- Showcase services and key information
- Make it easy for prospective learners to contact the school
